🔐 SshLens

Paste one SSH public key or a whole authorized_keys file. See each key's algorithm and size, comment, restricted-options prefix, SHA256 and MD5 fingerprints, and the OpenSSH randomart grid for each digest - decoded entirely in your browser with pure-JS SHA-256 and MD5.

  • ssh-rsa, ssh-dss, ecdsa-sha2-nistp256/384/521, ssh-ed25519, sk-* security keys
  • Multi-line authorized_keys with options (command=, no-pty, ...)
  • Fingerprints and randomart verified byte-for-byte against ssh-keygen -l / -lv
  • Warnings for weak RSA, deprecated DSA, truncated blobs, type mismatches
